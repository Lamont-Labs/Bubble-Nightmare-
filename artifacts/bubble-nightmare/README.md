# Bubble Nightmare

Bubble Nightmare is a one-thumb scarecrow-family arcade game. Swipe through
three or more matching bubbles, keep cursed bubbles away from the family, and
use each family member's special move once per round.

## Android download

The repository workflow builds an installable debug APK on pushes to `main`
and when manually started from GitHub Actions:

1. Open the repository's **Actions** tab.
2. Open a successful **Build Bubble Nightmare APK** run.
3. Download the `bubble-nightmare-android-apk` artifact.
4. On the Android phone, open the downloaded APK and approve installation if
   Android asks to allow installs from that browser or file manager.

The APK is a direct-install debug build, not a Play Store release.
